# vult 

[Vult](https://cheesefrog.github.io/vult/) is a multilingual Bible App with text-to-speech playback, disguised as a fully-functional calculator.

To enter Bible mode, input [70×7](https://www.biblegateway.com/passage/?search=matthew%2018:21-22&version=KJV) (Let the reader understand. How many times should I forgive my brother?).

Installable as a PWA (Progressive Web Application).
